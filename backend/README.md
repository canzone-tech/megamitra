# MegaGoldenClub Backend

Planned NestJS + TypeScript REST API.

Backend responsibilities include authentication/RBAC, program configuration, binary genealogy and volume accounting, commissions, eligibility, payments, ledger/wallet operations, rewards, draw execution, prize fulfilment, audit logging and CMS/theme integration.

MySQL remains authoritative for business and financial state. MongoDB is limited to flexible presentation/configuration documents and Redis is non-authoritative runtime infrastructure.
